# Tilt - the math and the ideas

Lessons for the systems with real math or a non-obvious idea behind them. Read a section, open the
constant it names, change it, and run the game. The point is to feel what the number does.

Where a number is a measurement it says how it was measured; where it is a target not yet tested it
says that too. Each section ends with things to try.
